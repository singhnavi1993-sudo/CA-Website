# Finsta - Financial & Business Consulting Website

A modern, high-performance financial and corporate consulting website with rich interactive animations, self-contained assets, custom typography (*Apfel Grotezk*, FontAwesome 5), and responsive layouts.

## Features
- **Hero & Analytics**: Dynamic growth indicator cards, team badges, and consultation CTA.
- **Interactive Accordions**: Project showcase with animated tab switching.
- **Service & Team Grids**: Photography cards with social popovers and hover effects.
- **Pricing & Testimonials**: 3-tier pricing plans with guarantee badges and client quote carousels.
- **Dark Mode Themes**: Topographical contour vector background styling.

## Running Locally
To run this website locally:
```bash
python -m http.server 3000
```
Then navigate to `http://localhost:3000` in your browser.
